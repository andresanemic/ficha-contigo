# Code not included

This public repository currently contains the project agreement, explanation and recorded evidence, not source code. The review begins with the problem, the access rules, the current test record and the limits on what those records can establish.

The source code is scheduled to open during the judges' review period under the [review-only license](../LICENSE). That license permits reading and cloning for evaluation. It does not grant permission to modify the code. When the source opens, review the pinned kernel digest before running `npm test`; the suite needs a deliberate re-pin and a fresh result.

Está previsto abrir el código durante el periodo de revisión de los jueces bajo la [licencia de solo revisión](../LICENSE). La licencia permite leer y clonar para evaluar. No concede permiso para modificar el código. Cuando se publique, revisa el digest fijado del kernel antes de ejecutar `npm test`; la suite requiere una nueva fijación deliberada y un resultado fresco.
